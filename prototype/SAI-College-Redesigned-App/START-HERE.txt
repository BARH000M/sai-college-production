SAI COLLEGE — VERSION 1087
كلية ساي التعليمية اليمنية الصينية

1. Extract the ENTIRE ZIP first / فك ضغط الملف بالكامل.
2. Open VISUAL-MOCKUP.html / افتح معرض مراجعة التصميم.
3. Choose one of nine roles, a screen and a tab.
4. Switch phone / tablet / web size. The six shortcuts below the preview match the supplied reference.
5. Open WEBSITE-PREVIEW.html for the public website design.
6. Navigate INSIDE the app to preserve sample changes during a session.
7. Use ملاحظات التصميم and download your notes before leaving the page.

Windows: OPEN-VISUAL-MOCKUP.cmd opens the review gallery.
OPEN-PREVIEW.cmd opens the full web app layout.
No installation, database or account is required.
All data is illustrative and resets on refresh. CSV import supports CSV UTF-8 exported from Excel, not XLSX.
Read QA-REPORT.md for checks and limitations. Earlier source folders are archived reference material.
