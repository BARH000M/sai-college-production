# Approved-reference design contract

Identity: كلية ساي التعليمية اليمنية الصينية / 也门赛艾教育学院 / SAI College.
Reference: visuals/APPROVED-REFERENCE.png. Exact supplied logo: browser-preview/assets/sai-logo.png.

Core palette: red #D00018, deep red #AE0011, navy #111D52, gold #D8A52F, white and pale blue-gray surfaces. Cairo is bundled locally. Arabic RTL is the default; Chinese/Pinyin remain learning content.

Phone: branded compact header, collapsed branch/session context, page title, horizontal tabs, white cards, role-specific five-item bottom navigation. Data tables scroll internally. Guardian cards, capacity/status rows and student/parent metric tiles use the reference's arrangement. Desktop: the same system with a right sidebar, search, context controls and a wider content grid.

The shell and all shared components apply to the full module inventory, including learning, authoring, finance, staff, reception, library, reports and settings. Seven optional later modules remain deferred.

The original logo is used intact in a red badge with rounded corners. No replacement crest is used in current screens. The approved artwork includes a different crest; only the layout is carried forward, with the user-supplied sunburst taking its place.
